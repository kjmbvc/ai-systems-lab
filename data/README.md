# Data provenance

These 13 short documents and 12 questions were newly authored as synthetic educational
examples for this project. No private, corporate, research participant or scraped material
is included. `wal-copy` is an intentional exact duplicate: ingestion yields 12 documents.
The examples and questions are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The project's source code has the separate MIT license.

This tiny English closed-corpus task is a functional fixture, not a general RAG benchmark.
Expected answers are manually specified. Exact match strips punctuation and case only;
valid paraphrases can score zero. Retrieval hit@2 and answer exact match are separate.
