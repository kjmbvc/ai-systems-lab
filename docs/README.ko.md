# AI Systems Lab 첫 구현

수학·최적화의 가정과 제약을 실행기, 데이터베이스, 프로세스, 큐의 실제 동작에
연결하는 CPU 실험 저장소입니다. 첫 범위는 재현 가능한 RAG 파이프라인과
자원 제약 DAG 실행기입니다. 장기 AI 시스템 연구 범위를 모두 구현한 것은 아닙니다.

## [Mathematical Rigor]

고정 합성 데이터와 순차 도착 질문을 가정합니다. 비용을 줄이되, 예열 후 요청의
p95 1.5초 이하, 정답 문자열 일치율 90% 이상, 검색 hit@2 95% 이상,
관측 오류율 0%, 프로세스 트리 RSS 표본 최대값 2GiB 이하를 실험 목표로 둡니다.
목표와 측정 결과는 구분합니다. CPU 시간·전력·비용은 직접 측정하지 않아
응답 지연을 비용의 대용 지표로만 사용합니다.

실행 가능한 노드는 선행 작업 완료, 동시 실행 개수 제한, 메모리 예약량 합계
제약을 모두 만족해야 합니다. 예약량은 OS의 강제 메모리 상한이 아닙니다.
모델 상주 메모리와 중간 결과도 있으므로 실제 RSS를 별도로 측정합니다.

캐시의 재계산 절감량은 조회·삽입·유지 비용을 넘어야 합니다. 반복 입력과
고유 입력을 모두 비교합니다. 평균 지연이 줄었다고 p99 개선을 일반화하지 않습니다.
표본 수가 작은 p95/p99는 해당 실행의 기술통계입니다.

## [CS Core & Backend Architecture]

수집 → 스키마 검증 → 정규화·해시 중복제거 → SQLite 저장/FTS5 인덱싱 →
검색 → 제한된 정책 분기 → 실제 모델 추론/응답 보류 → 평가를 연결했습니다.
원본 합성 문서 13건 중 1건은 의도한 중복이며 고유 문서는 12건입니다.
문서를 로컬 파일에서 수집하며 외부 웹 크롤러는 구현하지 않았습니다.

정책은 검색 결과가 없을 때 정해진 표현을 한 번 재작성하거나 `I don't know`로
보류합니다. 이는 도구 사용 흐름을 제한한 규칙 기반 에이전트이며 자율 LLM
계획기는 아닙니다. 검색된 출처 ID를 반환하지만 문장별 근거 일치 검증은 아닙니다.

DAG에는 순환/누락 의존성 검사, 동시성/예약량 제한, 시간 초과, 재시도,
실패 시 형제 작업 취소, 순수 작업 결과 재사용, SQLite 실행 기록이 있습니다.
`bounded_stream`의 유한 큐는 생산자에 역압을 전달합니다. 임의로 무제한
`query()` 태스크를 만들면 이 입구 제약을 우회하므로, 서비스화할 때 반드시
해당 입구를 연결해야 합니다. 현재 CLI/벤치마크는 순차 요청입니다.

SQLite 트랜잭션으로 문서와 검색 인덱스를 함께 교체해 재수집이 멱등적입니다.
외부 부작용을 포함한 exactly-once는 보장하지 않습니다. 일반 코루틴의 취소는
협력적이므로 CPU 모델을 별도 프로세스로 격리했습니다. Windows에서는 가상환경
Python 런처와 자식 프로세스까지 종료하는 경로를 테스트했습니다.

응답 캐시는 최종 답변을 재사용합니다. 검색 캐시나 KV prefix cache는 구현하지
않았습니다. FLAN-T5의 인코더 시간과 디코더 생성 시간을 나누어 기록하지만,
이를 decoder-only LLM의 prefill/TTFT/토큰별 decode 측정으로 간주하지 않습니다.

## [Low-Level Code & Open Source Reference]

Python 기준 구현과 실제 CPU 모델 측정을 먼저 수행했습니다. 예비 프로파일은
모델 추론이 주요 비용임을 보여 응답 캐시를 실험했습니다. Python 저수준 루프가
병목이라는 증거가 없으므로 C++/CUDA를 추가하지 않았습니다.

실제 모델은 공개 Apache-2.0 FLAN-T5-small이며 모델 revision을 고정했습니다.
모델 파일 SHA256, Python/라이브러리/SQLite 버전, 하드웨어, seed, 워크로드 ID,
소스 ID, 실행 명령과 요청별 결과를 기록했습니다. 유료 API·GPU를 사용하지 않습니다.
모의 모델 테스트와 실제 가중치 테스트는 분리했습니다.

재현 명령은 루트 `README.md`, 설계 상세는 `DESIGN.md`, 측정 결과와 ablation은
`RESEARCH.md`, 공식 출처와 라이선스는 `REFERENCES.md`에 있습니다. DDIA 공식
소개, MIT 분산시스템 및 CMU 데이터베이스 공식 강의 페이지를 관련 학습 자료로
연결했습니다. 읽지 않은 책의 구절이나 페이지는 인용하지 않았습니다.

## 한계와 다음 작업

합성 영어 12문항의 결과를 일반 RAG 품질로 해석할 수 없습니다. 필터와 응답 보류는
Alignment 완성이나 안전 보장이 아닙니다. 데이터 보호·프롬프트 주입 방어·강한
격리·프로덕션 인증/HTTP 서버는 별도 과제입니다. GPU/NCCL/RDMA/다중노드,
분산 학습/추론, 멀티모달/Physical AI, 협동 제어는 미구현·미측정입니다.

다음 최우선 작업은 공개된 더 큰 별도 평가 데이터와 open-loop 부하를 도입하여
검색 실패·근거 부정확성·대기시간을 측정하는 것입니다. 충분한 꼬리지연 표본,
예열/캐시 적중률/도착률별 실험 후 하드웨어 최적화 필요성을 판단합니다.
학회 제출은 수행하지 않았습니다.
